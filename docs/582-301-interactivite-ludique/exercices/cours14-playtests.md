# Exercice - Playtest de la classe et correctifs

> Exercice du [cours 14](../cours14.md#le-playtest-de-la-classe)

### 1. Préparer sa page

- [ ] Page itch.io en `Public`, **Community** à `Comments`, build Web à jour
- [ ] Tester la page en navigation privée

### 2. Jouer et commenter (≈ 45 min)

- [ ] Repérer dans la liste les **3 jeux qui suivent le sien**
- [ ] Pour chacun : environ 10 minutes de jeu, puis un commentaire selon le modèle (👍 J'ai aimé · 💡 J'aurais aimé · ❓ Et si… · 🐞 bug)
- [ ] Relire avant de publier : précis, constructif, aucun jugement négatif

### 3. Trier les retours reçus

- [ ] Bug ou blocage → issue `Must` · amélioration simple → `Could` · idée hors gel → `Won't`
- [ ] Deux testeurs bloqués au même endroit : priorité absolue

### 4. Correctifs et build de validation

- [ ] Corriger les `Must`, dans l'ordre
- [ ] Nouveau build Web → téléverser sur la page itch.io
- [ ] Tester la page depuis un autre poste

### 5. Le rituel

- [ ] Commit : `Build de validation apres playtests` → Push
