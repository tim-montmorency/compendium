## :material-numeric-1-circle: Création de compte

- [ ] Rendez-vous sur la page [créer un compte | Unity.com](https://login.unity.com/fr/sign-up).
- [ ] Cliquez sur « Continuer avec l'_e-mail_ »
- [ ] Utilisez votre **courriel du collège** (ex. : 1234567@cmontmorency.qc.ca)
- [ ] Inscrivez votre nom complet, un mot de passe, puis cliquez sur « Créer un compte »
- [ ] Confirmez l'adresse courriel via votre boîte de courriels

## :material-numeric-2-circle: Installation Unity Hub

Avant de procéder à l'installation, assurez-vous d'être connecté sur <https://unity.com/>. Si vous n'avez pas encore de compte, dirigez-vous vers la section Création de compte.

- [ ] Rendez-vous sur la page de [téléchargement de Unity](https://unity.com/download).

  !!! info "UnityHubSetup"

      Il se peut que l'exécutable se télécharge aussitôt. Dans le cas contraire, sélectionnez l'option de téléchargement correspondant à votre système d'exploitation (Windows ou Mac). Un fichier nommé **UnityHubSetup** sera téléchargé.

- [ ] Repérez le fichier **UnityHubSetup** que vous venez de télécharger et lancez-le.
- [ ] Suivez les instructions propres à votre plateforme afin d'installer Unity Hub.

  <!-- * Si vous n'avez pas encore créé de compte Unity, vous serez invité à le faire durant cette étape.
  * Une fois connecté à Unity Hub, celui-ci vous guidera pour installer la plus récente version LTS de l'éditeur Unity. Une version LTS est une version stable et supportée pour un temps défini. -->

## :material-numeric-3-circle: Adhésion au compte éducationnel gratuit

- [ ] Rendez-vous sur la page [Formule Unity Student | Unity.com](https://unity.com/fr/products/unity-student).<br>![](../assets/img/unity-student-supp.png){data-zoom-image .w-100}
- [ ] Cliquez sur le lien « Enseignement supérieur ».
- [ ] Remplissez l'étape 1 du formulaire.<br>Assurez-vous d'utiliser votre courriel du collège et de bien choisir « College Montmorency ».
  <br>![](../assets/img/unity-student-step1.png){data-zoom-image .w-10}

- [ ] Remplissez l'étape 2 du formulaire.<br>![](../assets/img/unity-student-step2.png){data-zoom-image .w-10}

  !!! note "Preuve du statut étudiant"
      
      Votre document doit inclure votre nom complet (identique à celui entré à l'étape 1), le nom/logo du collège et une date récente (comprise dans l'année scolaire en cours OU datée de moins de 90 jours). Exemples de documents : 
      
      - Horaire de cours
      - Reçu de paiement des frais de scolarité
      - Carte étudiante
  
- [ ] Cliquez sur « _Submit_ »
