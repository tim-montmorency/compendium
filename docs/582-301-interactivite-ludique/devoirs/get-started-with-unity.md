# Devoir - Get Started With Unity

## Objectif

Consolider ce qui a été vu au cours 1 : l'interface de Unity, la navigation dans une scène, la manipulation des GameObjects et un premier build web. Le tutoriel **Get Started With Unity** (~50 min) est **commencé en classe** - ce devoir consiste simplement à le terminer si ce n'est pas déjà fait.

## Consigne

1. Ouvre ton projet **Get Started With Unity** dans Unity Hub (créé en classe via **New project**)
2. Reprends le tutoriel là où tu étais rendu (fenêtre **Tutorials** dans l'éditeur)
3. Complète-le jusqu'au bout, incluant la dernière étape : **build web et publication sur Unity Play**
4. Prends une **capture d'écran de ton jeu publié sur Unity Play** (ou de la dernière étape complétée) et dépose-la dans ton dépôt GitHub, dans un dossier `devoirs/`

!!! info "Notes"
    * Si tu as tout terminé en classe : dépose ta capture d'écran, et c'est réglé
    * Le contenu est en **anglais** - note tes questions et apporte-les en classe
    * Profites-en pour **explorer** : déplace des prefabs, change le skybox, ajoute des VFX - tu ne peux rien briser

## Remise

* **Échéance :** début de la séance 2
* **Format :** capture d'écran dans ton dépôt (`devoirs/`)
* **Évaluation :** formative - ce devoir prépare le terrain, il n'est pas noté
