# Tutoriel pour commencer avec Unity

![](./banner.png){.w-100}

[^get]: [EN] [Get Started with Unity: In-Editor Tutorial](https://learn.unity.com/tutorial/get-started-with-unity-in-editor-tutorial)

## Préalables

Pour réaliser cet exercice, vous devez avoir un compte Unity et avoir accès à Unity Hub.

Au besoin, consultez le [guide de création de compte et d'installation de Unity Hub](../../extra/installation-unity-hub.md)

## Consignes

- [ ] Ouvrez Unity Hub
- [ ] Sous l'onglet ***Projects***, créez un nouveau projet.
- [ ] Sélectionnez le template « _Get Started With Unity_[^get] » (au besoin, cliquez sur _Download Template_)<br>![](./get-started.png){data-zoom-image .w-25}
- [ ] Nommez le projet « Commencer avec Unity »
- [ ] Sélectionnez un chemin pour enregistrer le projet (ex. : votre disque dur)
- [ ] Laissez le reste intact et cliquez sur « _Create project_ »
- [ ] Complétez les 5 étapes du tutoriel<br>![](./tuto-steps.png){data-zoom-image .w-25}

!!! tip "Tutoriel en français"
    
    - [Télécharger le fichier de traduction](./Get-Started-With-Unity-FR.unitypackage)
    - Dans le projet « _Get Started With Unity_ », dans le panneau « _Project_ », clic-droit sur le dossier « _Assets_ »
    - Choisir l'option « _Import Package_ » puis « _Custom Package..._ »
    - Choisir le fichier de traduction téléchargé.
    - Une petite fenêtre « _Import Unity Package_ » apparaitra. Cliquez simplement sur le bouton « _Import_ »
