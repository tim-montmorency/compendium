# Console

La fenêtre **Console** (en bas de l'écran, à côté de *Project*) affiche les erreurs et les messages qu'on imprime avec le code.

```csharp
Debug.Log("Hello World");
```

`Debug.Log(...)` imprime ce qu'on lui donne : un texte entre guillemets, ou une variable (ex. `Debug.Log(myInt);`).

!!! tip "En JS"
    C'est l'équivalent de `console.log(...)`.
