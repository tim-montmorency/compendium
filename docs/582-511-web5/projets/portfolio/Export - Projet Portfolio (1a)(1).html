Projet 1 : Votre Portfolio en ligne

40% de la note finale
Évaluation individuelle
Remise finale semaine 7

Vous êtes un·e intégrateur·rice multimédia junior sur le point de postuler pour un premier stage dans une agence web ou une entreprise créative. Pour convaincre un employeur potentiel de vous accorder une entrevue, vous devez lui soumettre votre portfolio en ligne : votre carte de visite numérique.

Soumettre un portfolio, ce n'est pas seulement livrer un beau site. C'est démontrer que vous savez concevoir un produit web de qualité professionnelle, de la planification initiale jusqu'au contrôle de la qualité finale, en prenant des décisions techniques réfléchies et en étant capable de les justifier.

À la mi-session, vous présenterez votre portfolio devant un jury composé de votre enseignante et, si possible, d'un·e professionnel·le invité·e du milieu, qui incarnera le rôle de l'employeur potentiel.

Responsabilités

Étudiant·e
  • Planifier et justifier ses choix technologiques
  • Concevoir les maquettes
  • Développer et commenter le code
  • Tenir un journal de bord
  • Utiliser Git
  • Mener le contrôle de qualité
  • Déployer
  • Défendre devant le jury
Enseignante
  • Fournir consignes, journal et grilles
  • Offrir la rétroaction (collective puis individuelle)
  • Coordonner l'invité·e
  • Évaluer selon la grille critériée
Invité·e (le cas échéant)
  • Jouer le rôle de l'employeur·e potentiel·le
  • Poser des questions sur les choix de conception
  • Offrir une rétroaction informelle du milieu

Consignes

Format du livrable — un site fait entièrement à la main, sans CMS ni thème préfabriqué. C'est ce qui démontre le mieux que vous savez concevoir et coder un site de zéro, une compétence directement valorisée par les employeurs du milieu.
Base obligatoire pour tous
  • Dépôt GitHub, commits réguliers et bien nommés
  • Site responsive (mobile et desktop), sans bogue majeur
  • Code commenté dans vos propres mots
  • Déploiement en ligne (GitHub Pages recommandé)
  • Journal de bord complété (JOURNAL.md)
  • Démarche de contrôle de qualité documentée
Vos choix technologiques : à justifier dans votre planification

Pour chacun des éléments suivants, choisissez l'approche qui convient le mieux à votre projet et expliquez la raison dans PLANIFICATION.md :

Données
BD ou fichier externe (JSON), affiché de façon asynchrone.
Interactivité
Un composant Vue.js de votre choix.
Animations
GSAP, une autre librairie, ou CSS pur.
Navigation
One-pager, multipages, ou autre.
Hébergement
GitHub Pages ou un autre service.
Journal de bord — 5 questions à chaque bloc de cours
  1. 1Qu'est-ce que j'ai accompli depuis le dernier bloc?
  2. 2Quelle a été ma principale difficulté et comment je l'ai surmontée?
  3. 3Qu'est-ce que j'ai appris que je ne savais pas avant?
  4. 4Quelle est ma prochaine étape concrète?
  5. 5Est-ce que j'ai utilisé l'IA? Si oui, pour quoi et qu'est-ce que ça m'a appris?
Auto-évaluation

À l'aide de la grille critériée fournie, vous évaluez vous-même votre portfolio avant la remise 3.

Tests par les pairs

Un·e collègue teste votre portfolio à partir d'une grille guidée; vous documentez les correctifs apportés.

Utilisation de l'IA — permise pour vous aider à apprendre et à déboguer, mais pas pour remplacer votre compréhension. Tout usage doit être documenté dans le journal de bord. Vous devez en tout temps être en mesure d'expliquer et de modifier votre code en direct.
