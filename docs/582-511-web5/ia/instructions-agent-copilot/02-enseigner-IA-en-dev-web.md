# Stratégies pédagogiques pour enseigner avec l'intelligence artificielle

## Objectif

Préparer les étudiants à travailler dans un environnement professionnel moderne utilisant l'intelligence artificielle.

---

# Ce qu'il faut enseigner

Les étudiants n'ont plus seulement besoin d'apprendre à programmer.

Ils doivent apprendre à :

- Collaborer avec l'IA
- Vérifier les réponses
- Poser de bonnes questions
- Comprendre le code produit

---

# Ce qu'il faut éviter

Ne pas enseigner :

- Les boutons précis
- Les positions dans l'interface
- Les détails spécifiques à une version

Les interfaces changent rapidement.

---

# Approche progressive

## Phase 1

Utiliser l'IA pour comprendre.

Exemples :

- Expliquer une fonction
- Expliquer une erreur
- Expliquer un concept

## Phase 2

Utiliser l'IA pour planifier.

Exemples :

- Produire un plan
- Décomposer un problème
- Définir une architecture

## Phase 3

Utiliser l'IA pour développer.

Exemples :

- Créer un composant Vue
- Créer une animation GSAP
- Ajouter une fonctionnalité

## Phase 4

Utiliser l'IA pour améliorer.

Exemples :

- Refactorisation
- Optimisation
- Documentation

---

# Activités pédagogiques suggérées

## Activité 1

Demander à l'IA d'expliquer un code.

Objectif :

Développer l'esprit critique.

---

## Activité 2

Comparer deux solutions générées par l'IA.

Objectif :

Analyser les avantages et les inconvénients.

---

## Activité 3

Faire produire un plan sans écrire de code.

Objectif :

Développer les compétences d'analyse.

---

## Activité 4

Faire valider le code généré.

Objectif :

Maintenir la responsabilité du développeur.

---

# Message pédagogique clé

L'IA accélère le travail.

Elle ne remplace pas la réflexion.

Le développeur demeure responsable du résultat final.
