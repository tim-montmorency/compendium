# Guide pédagogique - GitHub Copilot et IA en développement Web

## Objectif

Cette documentation résume les notions importantes concernant GitHub Education, GitHub Copilot, VS Code et l'utilisation de l'intelligence artificielle dans un cours moderne de développement Web.

Cette documentation sert de référence pour :

- Préparer les cours
- Préparer les laboratoires
- Accompagner les étudiants
- Intégrer l'IA dans l'apprentissage du développement Web

---

# Philosophie pédagogique

L'objectif n'est pas de remplacer la programmation par l'IA.

L'objectif est d'enseigner aux étudiants à :

- Collaborer avec l'IA
- Rédiger de bons prompts
- Vérifier les réponses générées
- Déboguer efficacement
- Comprendre le code produit

Le développeur demeure responsable :

- De l'architecture
- Des tests
- De la qualité du code
- De la validation finale

---

# GitHub Education

## Étudiants

Les étudiants peuvent faire une demande à GitHub Education.

Une fois approuvés :

- Accès au Student Developer Pack
- Accès à GitHub Copilot Student
- Accès à un nombre limité de crédits IA mensuels

## Enseignants

Les enseignants vérifiés obtiennent :

- GitHub Education Teacher
- GitHub Copilot Pro sans frais

---

# Activation de GitHub Copilot

Après l'approbation GitHub Education :

1. Ouvrir GitHub.
2. Ouvrir Copilot Settings.
3. Aller à la section Usage.
4. Cliquer sur Upgrade Plan.
5. Cliquer sur Get Access to GitHub Copilot.
6. Compléter l'activation.

---

# GitHub Copilot dans VS Code

GitHub Copilot est désormais intégré à VS Code.

Il offre :

- L'autocomplétion
- Le chat IA
- Les agents
- Le choix de modèles IA

---

# Les fonctionnalités principales

## Autocomplétion

Permet de compléter du code pendant la saisie.

Exemple :

```javascript
function addition(a, b) {
```

Copilot suggère automatiquement la suite.

## Chat

Permet :

- D'expliquer du code
- De comprendre une erreur
- De générer des exemples
- De répondre à des questions

## Agent

Permet :

- D'analyser un projet
- De modifier plusieurs fichiers
- D'ajouter une fonctionnalité
- De réaliser des tâches complexes

# Différences entre les versions

GitHub modifie fréquemment l'interface.

Certaines versions affichent :

- Ask
- Edit
- Agent

D'autres affichent :

- Ask
- Plan
- Agent

D'autres affichent :

- Agent
- Models

Les concepts demeurent identiques malgré les changements d'interface.

Il est préférable d'enseigner les concepts plutôt que les boutons.
