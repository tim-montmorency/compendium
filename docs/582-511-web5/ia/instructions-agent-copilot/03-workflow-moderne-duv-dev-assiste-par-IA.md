# Workflow moderne du développeur Web assisté par IA

## Vision générale

Le métier de développeur évolue.

Le développeur moderne agit davantage comme :

- Architecte
- Analyste
- Intégrateur
- Validateur
- Réviseur de code

---

# Processus recommandé

## Étape 1

Définir le besoin.

Exemple :

Créer une application de gestion de tâches.


## Étape 2

Produire un plan.

Prompt :

Donne-moi un plan détaillé.
Ne génère aucun code.


## Étape 3

Développer progressivement.

Exemples :

- Composants Vue
- HTML
- CSS
- JavaScript


## Étape 4

Déboguer avec l'IA.

Exemples :

- Messages d'erreur
- Analyse de problèmes
- Suggestions de correction


## Étape 5

Valider manuellement.

Toujours :

- Tester
- Vérifier
- Réviser

---

# Utilisation de Vue.js

Prompts recommandés :

Créer un composant Vue 3 Options API.

Ajouter LocalStorage.

Ajouter un système de filtres.

Refactoriser selon les bonnes pratiques Vue.

---

# Utilisation de GSAP

Prompts recommandés :

Créer une animation d'entrée.

Créer une animation avec ScrollTrigger.

Créer une séquence avec stagger.

Expliquer chaque propriété utilisée.

---

# Utilisation responsable des crédits IA

## À faire

✅ Poser des questions précises

✅ Générer une fonctionnalité à la fois

✅ Réutiliser le contexte du projet

✅ Utiliser Auto la majorité du temps


## À éviter

❌ Génère tout mon projet

❌ Réécris toute l'application

❌ Produis une énorme quantité de code inutile

❌ Utiliser systématiquement les modèles les plus puissants

---

# Comprendre les coûts IA

## Token

Un token est une petite unité de texte.

Plus la conversation est longue :

→ plus il y a de tokens.

## Input

Texte envoyé au modèle.

## Output

Texte généré par le modèle.

## Cache Write

Création du contexte.

## Cache Read

Réutilisation du contexte existant.

---

# Recommandations pour les étudiants

Pour la majorité des exercices :

- Utiliser Auto

Pour les explications simples :

- Utiliser les modèles économiques disponibles

Pour les gros projets :

- Utiliser un modèle plus avancé seulement lorsque nécessaire

---

# Message final

Les crédits IA ne servent pas à remplacer l'apprentissage.

Ils servent à accélérer l'apprentissage.

La meilleure utilisation de l'IA est celle qui augmente la compréhension de l'étudiant.
