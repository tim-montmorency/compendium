# HyperUI

![](./giphy.gif){.w-100}

L'objectif de cet exercice est d'appliquer sur une page Web certaines composantes HTML tirées du site <https://hyperui.dev/>.

## Résultat attendu

![](./hyper-ui-fixed.png){data-zoom-image .w-50}

## Consignes

- [ ] [Accepter le devoir Classroom 50](https://classroom50.org/tim-w3/web-3/assignments/hyperui/accept)
- [ ] Cloner le dépôt avec GitHub Desktop
- [ ] Ouvrir le dossier cloné dans VSCode

---

- [ ] Dans `index.html`, connectez Tailwindcss par CDN
- [ ] Dans `<body>`, ajouter les 4 composantes Marketing suivantes :
  - Entête (_Header_)
  - Bannière (_Banners_)
  - Inscription à l'infolettre (_Newsletter Signup_)
  - Pied de page (_Footer_)<br>![](./hyper-ui-pasted.png){data-zoom-image .w-10} 
- [ ] Formatter le code HTML (clic-droit sur le code et choisir « Format document » / « Mettre le document en forme »)
- [ ] Avec des classes Tailwind, ajuster le champ texte de l'infolettre :
  - Padding sur tous les côtés de `1rem`
  - Fond blanc
- [ ] Uniformiser les couleurs utilisées (turquoise et indigo) par une seule couleur Tailwind de votre choix
