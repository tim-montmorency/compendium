# Cours 15 | Démonstrations et entrevues

![](./assets/images/calm.webp){.w-100}

Dernier cours&nbsp;! Le projet final a été remis la veille, à 23 h 59. Aujourd'hui, il est présenté, puis expliqué.

## Déroulement

| Moment | Durée | Ce qui se passe |
| :--- | :--- | :--- |
| Accueil | 5 min | Ordre de passage, consignes |
| **Démonstrations** | 2 min chacune | Devant le groupe&nbsp;: le site en ligne, le jeu, une ou deux animations |
| Pause | 10 min | |
| **Entrevues individuelles** | environ 4 min chacune | Au poste de l'enseignant, selon l'ordre de passage |

L'ordre de passage est le même pour les démonstrations et pour les entrevues. Une fois l'entrevue terminée, vous pouvez quitter.

## L'entrevue

- Le répertoire GitHub remis est ouvert à l'écran.
- Deux passages du code, choisis à l'avance par l'enseignant, sont à expliquer&nbsp;: **ce qu'ils font** et **comment**.
- Une question de modification&nbsp;: prédire l'effet d'un changement.
- Le code peut être consulté, mais sans IA, sans notes et sans aide.

Les critères et leur pondération sont dans l'[énoncé du projet final](./devoir/projet-final.md#demonstration-et-entrevue).

!!! danger "Présence obligatoire"

    Une absence sans motif valable entraîne la note 0 pour le projet final, même si le projet a été remis (PIÉA, art. 7.2).
