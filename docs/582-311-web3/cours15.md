# Cours 15 | Démonstrations et entrevues

![](./assets/images/calm.webp){.w-100}

Dernier cours ! Le projet final a été remis la veille, à 23 h 59. Aujourd'hui, il est présenté, puis expliqué.

## Déroulement

| Moment | Durée | Ce qui se passe |
| :--- | :--- | :--- |
| Accueil | 5 min | Ordre de passage, consignes |
| **Démonstrations** | 2 min chacune | Devant le groupe : le site en ligne, le jeu, une ou deux animations |
| Pause | 10 min | |
| **Entrevues individuelles** | environ 2 min chacune | Au poste de l'enseignant, selon l'ordre de passage |

L'ordre de passage est le même pour les démonstrations et pour les entrevues. Une fois l'entrevue terminée, vous pouvez quitter.

## L'entrevue

- Le répertoire GitHub remis est ouvert à l'écran.
- L'enseignant désigne, sur le moment, **n'importe quelle partie du code**, à expliquer : **ce qu'elle fait** et **comment**.
- Une question de modification : prédire l'effet d'un changement.
- Le code peut être consulté, mais sans IA, sans notes et sans aide.

L'entrevue compte pour **20 % de la note du projet**. Les critères et leur pondération sont dans l'[énoncé du projet final](./devoir/projet-final/index.md#demonstration-et-entrevue).

!!! danger "Présence obligatoire"

    Une absence sans motif valable entraîne la note 0 pour le projet final, même si le projet a été remis (PIÉA, art. 7.2).
